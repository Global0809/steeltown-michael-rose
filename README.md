# Steeltown Michael Parfum

A static fragrance website featuring the supplied Pink and Silver 3D bottles, Shader Lines in a layered pink spectrum with its original motion, campaign photography, film and music.

Published with GitHub Pages from the root of the codex/publish branch. All asset paths are relative, including the locally served Three.js bundle and Draco decoder. No build step is required for this published edition.

Shader Lines is credited to Ali Imam and was supplied by the site owner. Brand assets and media were supplied or commissioned for this website. Third-party runtime notices are included in vendor/.

Online checkout is currently unavailable. The site displays the supplied catalog values: Eau de parfum, 150 ml, $199 USD, Pink and Silver finishes. Automatic English film captions await final proofreading.
